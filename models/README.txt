VICE CITY RP v16 — 4K PBR MATERIAL PACK

Peningkatan nyata dari v15:
- Aspal 4K: albedo, normal, roughness lokal.
- Fasad beton 4K: albedo, normal, roughness lokal.
- Trotoar 2K dengan pola paving.
- Material jalan, gedung, dan trotoar dihubungkan ke tekstur resolusi tinggi.
- Tidak mengunduh tekstur saat permainan berjalan; semua map baru berada di folder assets/textures.

PERSYARATAN / CATATAN
- Ini peningkatan material dan tekstur, bukan aset AAA lengkap seperti GTA V.
- Model gedung, kendaraan, dan karakter belum seluruhnya diganti dengan model fotogrametri/AAA.
- Tekstur 4K membutuhkan VRAM dan RAM lebih besar. Jika perangkat mengalami patah-patah,
  gunakan resolusi layar lebih rendah atau kembalikan tekstur 2K.
- Untuk model 3D eksternal, letakkan file GLB milik sendiri di folder models/ dengan nama
  player.glb, sportcar.glb, dan city.glb sesuai kebutuhan.
- Jalankan lewat local web server atau GitHub Pages, bukan file://.
